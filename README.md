# tic

## امتیازدهی

- برد: ۵۰ امتیاز برای برنده
- مساوی: ۲۵ امتیاز برای هر بازیکن
- باخت: بدون امتیاز

برای دیدن رتبه‌بندی بازیکنان، از گزینهٔ «برترین بازیکنان» در منوی اصلی استفاده کنید.

دکمه‌های بازگشت با فلش معمولی نمایش داده می‌شوند.

## بازی inline

با انتخاب نتیجهٔ X یا O، پیام بازی دکمهٔ «ورود به بازی» را نشان می‌دهد. بازیکن دوم با زدن همان دکمه وارد بازی می‌شود؛ فعال‌بودن بازخورد inline در BotFather برای این روند لازم نیست.
